# CNN Pet Image Classifier (Cat vs Dog)

This project is a Deep Learning model built using Convolutional Neural Networks (CNN) to classify images of cats and dogs.

## 📌 Project Description
A binary image classification model that predicts whether an input image is a **cat or a dog** using a CNN built with TensorFlow and Keras.

---

## 🧠 Model Architecture
- Conv2D (32 filters, 3x3)
- MaxPooling2D
- Conv2D (32 filters, 3x3)
- MaxPooling2D
- Flatten
- Dense layers
- Output layer with Sigmoid activation

---

## ⚙️ Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- ImageDataGenerator
